If this is your first time setting up Firestore, click the button below to upload all initial Team members (6 creators), Events (Summit + 6 workshops), Gallery images (6 photos), About text, and Contact information into your database automatically.

🛡️ Firestore Security Rules

Copy and paste these security rules into your Firebase Console → Firestore → Rules tab to allow the public website to read data, while restricting writing/editing strictly to logged-in administrators: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}
